# 8. 相談型プロンプト設計：Thinkingモデルと上手に話す（発展）

## ねらい
生成AIを「命令に従う機械」ではなく、「一緒に考える相棒」として活用するコツを身につける。

![AIは相談する相棒](../assets/images/08_partner.png)
*AIは「命令する相手」ではなく「相談する相棒」*

## やさしく理解するポイント
いまの生成AIは、指示をそのまま実行するだけでなく、
「目的は何か」「どこまでやるべきか」「優先度は何か」を考えながら答えています。
だからこそ、強い命令よりも**相談するようにお願いする**方が、良い結果になりやすいです。

## 命令型と相談型のちがい
**命令型**: ゴールも手順も形式も全部決める  
**相談型**: 目的と条件だけ伝え、最適な進め方をAIに考えてもらう

![みんなで相談して決める](../assets/images/08_collaboration.png)
*相談型：目的と条件を共有して、一緒に答えをつくる*

## 相談型プロンプトの基本形
```
〇〇について検討しています。
目的は□□です。

条件としては、
- △△
- ◇◇

この前提で、最適な進め方や構成を提案してもらえますか？
```

## 具体例（そのまま使える形）
### 例1: 研修の構成案を相談する
```
新任ボランティア向け研修を検討しています。
目的は「初参加でも安心して活動できる状態をつくる」ことです。

条件としては、
- 60分以内
- 参加者は高齢者も含む
- 事前資料はA4 1枚まで

この前提で、最適な進め方や構成を提案してもらえますか？
```

### 例2: 手順書の章立てを相談する
```
イベント当日の受付マニュアルを作成しています。
目的は「初めてでも迷わず受付を回せること」です。

条件としては、
- 受付担当は2名
- 受付開始は9:30
- 参加者は100名程度

この前提で、章立てと見出し案を提案してもらえますか？
```

### 例3: SNS投稿の方向性を相談する
```
地域の清掃活動の告知文を作りたいです。
目的は「若い世代の参加者を増やすこと」です。

条件としては、
- X（旧Twitter）向けで140〜180文字
- 明るく親しみやすいトーン
- 参加条件（持ち物なし、参加無料）を必ず入れる

この前提で、伝わりやすい文案を複数提案してもらえますか？
```

### 例4: 企画アイデアの整理を相談する
```
高齢者向けの交流イベントを企画しています。
目的は「孤立感を減らし、地域のつながりをつくる」ことです。

条件としては、
- 参加費無料
- 2時間以内
- 会場は公民館

この前提で、企画アイデアを5つ提案し、メリット・注意点も教えてもらえますか？
```

### 例5: 比較検討を相談する
```
ボランティア募集チラシの配布方法を検討しています。
目的は「短期間で参加者を増やすこと」です。

条件としては、
- 予算は1万円以内
- 2週間以内に実施
- 人手は3人

この前提で、配布方法の候補を比較し、最適案を提案してもらえますか？
```

### 例6: 失敗しにくいお願いの言い方
```
講座の最後に配る振り返りシートを作りたいです。
目的は「参加者が今日の学びを言葉にできること」です。

条件としては、
- 記入時間は5分以内
- 質問は5つまで
- 初めての人でも答えやすい表現

この前提で、質問項目を提案してもらえますか？
```

## 使い分けの目安
**命令型が向く**: 形式が厳密／安全要件が最優先／手順の再現性が重要  
**相談型が向く**: 企画／教材設計／解説文づくり／比較検討

## まとめ
生成AIの力を引き出すカギは、「正しい命令」よりも「よい問い」です。  
目的と条件を伝えた上で、AIに考えさせる——これがThinkingモデル時代の基本姿勢です。

![よい問いが扉を開く](../assets/images/08_key.png)
*よい問い（プロンプト）が、新しい世界の扉を開く*
